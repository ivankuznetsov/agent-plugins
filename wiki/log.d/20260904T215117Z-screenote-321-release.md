# Screenote 3.2.1 release

Prepared Screenote plugin 3.2.1 for screen-specific Page identity. The plugin
and its external CLI baseline now reject snapshot manifests that group
neighboring screens under one Page while retaining desktop, tablet, and mobile
as variants and later captures as versions.

The external minimum advances to Screenote CLI v0.4.1 from PR 18 at
`cce90049d1335413bd903d7da4882d20615fa5d3`. Canonical skills, generated host
adapters, manifests, provenance, tests, and the semantic lock advance together.
