# Screenote 3.2.0 release

Prepared Screenote plugin 3.2.0 for image-aware feedback. The release raises
the external CLI floor to v0.4.0, retrieves root and reply attachments into a
private local tree, and supports one explicitly requested image per comment.

The canonical Claude/Codex skill, generated Pi/OpenClaw adapters, launcher
contract, offline behavior tests, protected integration, manifests, catalogs,
and semantic lock advance together.
